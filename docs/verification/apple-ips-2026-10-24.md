# Apple IPS static inspection verification — 2026-10-24

## Scope

PR #6511 adds portable `inspect_apple_ips` / `inspect-apple-ips` over one
caller-selected local file. The metadata must identify string `bug_type`
`"309"`; stackshots and other report kinds remain unsupported. No target is
executed, no deep engine starts, and no atos/dSYM lookup is performed. These
checks do not qualify live macOS state, symbolication or Mach-O UUID joins.

The source contract preserves integer literals beyond IEEE-754 precision,
observed type mismatches and partial coverage. The frame address is derived
from its image's base plus its recorded offset, as described in
[Apple's crash JSON documentation](https://developer.apple.com/documentation/xcode/interpreting-the-json-format-of-a-crash-report).
That documentation does not provide a 64-bit bound for every numeric field;
the parser therefore bounds representation cost without truncating values.

## Review corrections and ownership

The contributor's `80ad2a02e9c6cbe248d58d78a7a79753bcc09f79` already projects
documented JSON members and checks thread/frame/image/register allowances
before materializing each row. Unknown members are syntax-checked without
retaining their values. Producer controls include a budget error before an
invalid next item, wrong-type collections, physical frame depth with inline
rows, and the DEAD10CC decimal near miss. Source inspection alone does not
establish the runtime checks below.

Further negative controls expose three remaining boundaries:

- Two contradictory thread/image coverage reports were accepted by the
  service. Coverage now agrees with the retained arrays before Evidence is
  issued. Already cancelled requests also preserve the exact caller reason.
- A 20,001-digit image base expanded into 512 derived frame addresses despite
  a small input file. The field reader now owns an 8 MiB default / 64 MiB
  maximum UTF-16 allowance for recorded decimal/hex fields. Conservative
  reservations precede conversion and arithmetic. Source BigInts are reused;
  derived sums are not retained in a cache. Repeated appearances count
  separately, including a service control using the same object twice.
- A 20,013-character image architecture appeared 513 times in a 512-frame
  report. Frames now retain their recorded `image_index`; architecture, UUID
  and `uuid_unknown` belong to the image once. The old per-frame copies and
  superseded field-access helpers are removed.

Each defect has a failing control before its correction. Raising the integer
allowance to 64 MiB preserves the 512-frame decimal facts exactly. The
allowance is per call, requires no restart, and is separate from file-size,
row, wire and client-buffer limits. Refusal is a typed capacity error without
partial success. A refused task is not treated as a completed-task speedup.
